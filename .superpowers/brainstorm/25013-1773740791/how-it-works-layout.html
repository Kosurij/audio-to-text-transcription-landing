Как переработать «How it works»?

Features станет крупным текст+GIF (как Transkriptor). HowItWorks нужен другой стиль чтобы не сливаться.

A

Горизонтальный прогресс с коннекторами

3 шага в ряд, соединены линией. Нет медиа — только большой номер, заголовок, текст. Компактно, не похоже на Features.

1
Install Extension
One click from Chrome Web Store. No account needed.
2
Upload or Record
Drag a file or hit Record to capture mic or tab.
3
Get Transcript
Accurate text in seconds. Edit, copy, download.
B

Вертикальные шаги с огромными номерами

Слева огромная цифра (декоративная, полупрозрачная), справа заголовок + описание. Полосы чередуются по фону. Никаких медиа — чистая типографика.

01
Install the Extension
Add to Chrome in one click — no account, no sign-up required.
02
Upload or Record Audio
Drop a file or record from mic or browser tab in real time.
03
Get Your Transcript
Text appears in seconds — edit, copy, or download as TXT.
C

Оставить шаги с медиа, но другой фон/цвет

Сохранить раскладку текст+медиа, но сделать HowItWorks на ярком акцентном фоне (тёмный, синий или градиент). Features на белом/сером — визуально отличаются.
