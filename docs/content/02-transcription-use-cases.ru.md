# Когда записывать звук вкладки, а когда — микрофон

В нашем расширении есть несколько режимов записи звука: через микрофон, захват звука из открытой вкладки браузера, комбинированный (микрофон + вкладка). Давайте рассмотрим сценарии, когда может пригодиться каждый:

- **Микрофон – чтобы записать свой голос.** Например, это позволит быстро надиктовать заметку, сохранить мысль или проговорить черновик письма, который впоследствии преобразуется в текст для дальнейшей работы
- **Вкладка – чтобы записать то, что звучит в браузере.** Например, вы прослушиваете лекцию, вебинар или видео/аудио. Если файла для загрузки нет, запишите звук во время воспроизведения, а затем получите текстовую расшифровку
- **Микрофон и вкладка – чтобы сохранить обе стороны разговора.** Если звонок проходит в браузере, этот режим позволяет записать и собеседников из вкладки, и ваши ответы через микрофон
