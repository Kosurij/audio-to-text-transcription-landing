# Landing Page Redesign — Design Spec

**Date:** 2026-03-17
**Scope:** Полный редизайн лендинга (структура + визуальный стиль). Расширение не затрагивается.

---

## Контекст

Chrome-расширение для транскрипции аудио в текст (Groq + Whisper AI). Текущий лендинг устарел: hero — только текст на фоновом видео, нет превью продукта, нет социального доказательства. Конкуренты (Transkriptor, tactiq.io) активно используют GIF-демо и превью UI.

**Аудитория:** профессионалы (A) и студенты/исследователи (B), с прицелом на широкую.
**Стек:** Astro + Vue 3, существующая кодовая база сохраняется.

---

## Визуальный стиль

**Направление:** Minimal — белый/slate фон, синий акцент (`#2563eb` / `#3b82f6`), тонкие тени.

**Обе темы обязательны:**
- Light: белый фон (`#ffffff`), серый текст (`#64748b`), синий акцент `#2563eb`
- Dark: тёмный slate (`#0f172a`), приглушённый текст (`#475569`), синий акцент `#3b82f6`

**Переключение тем:** существующий механизм `html[data-theme='dark']` сохраняется. Кнопка-переключатель уже есть в NavigationBar — оставляем как есть. Никаких изменений в логику темы не вносится.

**Типографика:** крупные жирные заголовки (`font-weight: 800`, `letter-spacing: -0.04em`). Семейство шрифтов — то, что уже задано глобально в Layout.astro (менять не нужно).

**Без интерактивных демо** — только видео, GIF, скриншоты и текст.

## Визуальные материалы (блокирующий prerequisite)

**Владелец:** автор проекта (Yuri).
**Политика placeholder:** во время разработки использовать цветные блоки-заглушки; заменить на реальные материалы перед финальным QA.

Что нужно создать до финального QA:
- [ ] Скриншот расширения (sidebar открыт, вкладка Record активна, есть текст транскрипции)
- [ ] GIF: загрузка файла → транскрипция появляется (≈5–10 сек, зацикленный)
- [ ] GIF: запись микрофона → текст появляется (≈5–10 сек, зацикленный)
- [ ] GIF или MP4: запись вкладки браузера → текст (≈5–10 сек)
- [ ] Скриншот экспорта (TXT/DOCX/SRT кнопки)
- [ ] Скриншот Chrome Web Store страницы расширения

В HeroSection floating panel: **зацикленный GIF** расширения (~400×600px), показывающий вкладки Record/Upload/Tab, waveform, текст транскрипции, кнопки экспорта.

## Контент (блокирующий prerequisite)

Следующий контент нужно подготовить до разработки соответствующих секций:

**Stats (SocialProofBar + HeroSection):** Проверить актуальные цифры в Chrome Web Store перед реализацией. Placeholder-значения для разработки: "10,000+ Users", "★ 4.8", "500+ Reviews", "95%+ Accuracy".

**Testimonials:** Подготовить минимум 5 реальных отзывов из Chrome Web Store (звёзды, цитата, имя пользователя, ссылка на отзыв). До готовности — placeholder-карточки.

**FAQ:** Обновить список вопросов-ответов под новую структуру лендинга. Текущие вопросы в `FAQSection.vue` использовать как основу. До готовности — оставить существующие.

**Подзаголовок Hero:** написать 2–3 строки, ориентированные на профессионалов и студентов. Пример: "Chrome extension for meetings, interviews and lectures. Upload audio files, record mic or browser tab — get accurate text instantly."

## Структура страниц

### 1. NavigationBar (минимальные правки)
- Sticky + `backdrop-filter: blur(12px)` — уже реализовано, проверить корректность
- Light: `rgba(255,255,255,0.88)` фон + border-bottom
- Dark: `rgba(15,23,42,0.88)` фон + border-bottom
- Лого слева → ссылки по центру (Features, How it works, FAQ) → CTA справа
- CTA: "Install free" → Chrome Web Store
- Тема-переключатель: оставить на месте

### 2. HeroSection (полная переработка)
**Layout:** split — левая колонка (текст + CTA + stats) и правая (превью продукта).

**Левая колонка:**
- Badge: "✦ Powered by Groq + Whisper AI"
- H1: "Audio to Text / in seconds." (вторая строка — градиентный текст blue→sky)
- Подзаголовок: 2–3 строки (контент — см. раздел Контент)
- CTA: "+ Add to Chrome — It's free" (primary, с shadow)
- Подпись: "No account required · Works in Chrome"
- Stats: 10k+ Users · ★ 4.8 · 95%+ Accuracy (цифры — проверить перед запуском)

**Правая колонка:**
- Зацикленный GIF расширения (~400×600px) во floating-панели
- Тень: `box-shadow: 0 8px 40px rgba(0,0,0,0.1)`
- В dark mode тень: `box-shadow: 0 8px 40px rgba(0,0,0,0.4)`

**Удалить:** фоновое видео `background.mp4` — отвязать от компонента. Файл можно оставить в репозитории или удалить — на усмотрение.

**Mobile:** колонки складываются вертикально (текст сверху, GIF снизу).

### 3. SocialProofBar (новая секция)
Горизонтальная полоса:
- "10,000+ Users"
- "★ 4.8 · 500+ Reviews on Chrome Web Store"
- Chrome Web Store логотип/badge
- Product Hunt badge — **включить только если есть активная страница на Product Hunt**; если нет — не добавлять.

**Mobile:** элементы wrap в 2 строки.

### 4. CompatibilitySection (новая секция)
Заголовок: "Works anywhere you record audio"
Логотипы: Google Meet, Zoom, Microsoft Teams, YouTube, Spotify + "Any MP3/WAV file".
**Источник логотипов:** официальные brand kit страницы каждой платформы или Simple Icons (simpleicons.org) — лицензия CC0/MIT. Использование в контексте совместимости не требует разрешения.
Layout: горизонтальная строка с иконкой + подписью.
**Mobile:** 2–3 логотипа в ряд, wrap.

### 5. FeaturesSection (переработка BenefitsSection)
**Layout:** чередующийся — текст/GIF слева-справа поочерёдно.
3–4 фичи:
1. **Lightning Fast** — загрузка файла → результат за секунды (GIF)
2. **Record Mic or Tab** — запись прямо в браузере (GIF)
3. **Multiple Export Formats** — TXT, DOCX, SRT (скриншот)
4. **Privacy First** — нет хранения данных (иконка/иллюстрация, без GIF)

Каждая фича: H3 + 2–3 строки текста + медиа.
**Mobile:** медиа над текстом, одна колонка.

### 6. HowItWorksSection (переработка)
**Удалить:** YouTube iframe.
**Вместо:** 3 шага, пронумерованных, с медиа.

1. **Install the Extension** — скриншот Chrome Web Store
2. **Upload or Record Audio** — GIF drag & drop или кнопка записи
3. **Get Your Transcription** — GIF появления текста + кнопки экспорта

Layout: вертикальный список, медиа сбоку от текста.
**Mobile:** медиа над текстом, одна колонка.

### 7. TestimonialsSection (новая секция)
Контент: минимум 5 реальных отзывов из Chrome Web Store (см. раздел Контент).
Layout: сетка 2–3 карточки в ряд.
Карточка: ★★★★★ + цитата + имя + ссылка "View on Chrome Web Store".
**Mobile:** одна колонка.

### 8. FAQSection (стиль обновить, контент переработать)
Аккордеон. Вопросы — см. раздел Контент.
Визуальный стиль обновить под новую цветовую схему.

### 9. CTASection (стиль обновить)
Крупный заголовок + CTA кнопка. Существующая структура сохраняется.

### 10. AppFooter (переработка)
Многоколоночный layout:
- Колонка 1: Лого + краткое описание
- Колонка 2: Product — Features, How it works, FAQ
- Колонка 3: Legal — Privacy Policy (существующая страница `/privacy`), Uninstall (существующая страница `/uninstall`)
- Нижняя строка: © 2024–2026 Audio to Text Transcription

Существующие страницы `/privacy` и `/uninstall` — не трогаем, только добавляем ссылки в футер.
**Mobile:** колонки складываются вертикально.

## Что НЕ входит в scope

- Редизайн самого расширения
- Страницы `welcome`, `privacy`, `uninstall` — не трогаем (только ссылки в футере)
- Функциональные интерактивные демо
- Блог, статьи, дополнительные маркетинговые страницы
- Изменение логики тёмной темы
